**Release Version / 版本**: `v0.11.0`  
**Date / 发布日期**: 2026-09-13  
**Theme / 核心主题**: 现有前端重构落地 · 真实 Agent 能力 · 全局 Gura 助手 (Frontend Refactor, Real Agent Capabilities, and Global Gura Assistant)

## 中文说明 (Release Notes - Chinese)

### 1. 版本概览

GuraNovel `v0.11.0` 是一个里程碑式的主力版本，围绕“**现有前端重构落地 + 真实 Agent 能力 + 全局 Gura 助手**”三大支柱全面升级。本版本使用户能够在统一、稳定且高度沉浸的工作区中完成小说的大纲构思、正文起草、批注反馈、多维审阅、模拟读者检验和最终定稿；同时引入全局助手 Gura，为创作者提供跨页面操作指引、工程上下文查询与有界快捷操作。

---

### 2. 核心新特性与改动

#### 🌟 支柱一：现代化 Studio 前端重构与持久化工作流接通
- **统一导航与路由恢复 (#258)**：接通 Dashboard、Detail 与 Studio 页面流转，URL 深度链接精准记录工程与章节状态；支持浏览器前进/后退，并在页面跳转前自动冲刷正文保存队列，彻底杜绝数据丢失。
- **五阶段全生命周期接通与重试解耦 (#261)**：
  - **大纲 (Outline)**：明确区分大纲确认与正文起草，确认大纲版本后自动开启作者门禁并进入起草。
  - **起草 (Draft)**：正文自动保存绑定作者身份；支持对批注与通用要求生成不可变提交快照，提交前冲刷草稿，支持幂等重试（`sessionStorage` 故障恢复）；草稿前置校验失败以友好 Toast 提示，重试修改按钮与审阅按钮严格解耦，彻底避免界面状态死锁。
  - **审阅 (Review)**：依次接入责任编辑（`editor_agent`）、总编（`chief_editor_agent`）和设定编辑（`lore_agent`）三位一体审阅报告；支持独立折叠面板、阻塞/建议项筛选、非阻塞警告显式放行决策以及针对选中问题的定向修订。
  - **读者剧场 (Reader)**：支持 6 类读者画像（`studio_*`）的个体邀请与预算控制，流式展现多轮讨论与主持人仲裁报告，严格恪守**只读诊断、绝不擅改正文**原则。
  - **定稿 (Final)**：本地化章节定稿（`finalizeStudioChapter`），校验 `COMPLETED` 状态，明确不夸大外部平台自动发布。
- **编辑交互与连续动效稳定 (#259)**：全视口严格杜绝整页滚动，保持超宽屏、桌面及窄屏下的布局稳定性；内联评论气泡与浮动控制板自适应避让侧边栏，支持拖拽重排与微交互反馈。
- **批注与手动还原点持久化 (#260)**：新增数据库级批注与通用要求存储、不可变快照记录；提供手动创建还原点机制，并在还原时自动建立“还原前备份”，确保历史随时可溯。

#### 🤖 支柱二：专职 Agent 真实模型全线接通与质量基准
- **大纲正文上下文全量传递 (#262, #263)**：初稿生成、用户批注修改与审阅修订流程强制获取并传递完整大纲正文，彻底解决真实模型调用前 `ContextInsufficientError` 隐患。
- **6 类真实读者画像注册与驱动 (#265)**：完整注册 `studio_plot`, `studio_character`, `studio_world`, `studio_emotion`, `studio_language`, `studio_casual` 对应 Reader Profile，确保真实模型网关可正确加载 6 类读者的视角偏好、严苛度与分析维度。
- **构思与工程维护 Agent 真实模型接入 (#264)**：概念生成、设定维护与角色设定分析全面接入真实 LLM 调用。
- **OpenAI 兼容网关鲁棒性与真实质量基准 (#266, #270)**：
  - 加固结构化输出传输（针对不支持 `json_schema` 模式的 DeepSeek 等网关自动降级至标准 `json_object` 并清洗 Markdown 标记，同时保持 100% 严格 Pydantic 校验）。
  - 执行端到端真实模型质量评测（模型 `deepseek-flash`，6/6 用例全部通过，综合评分 **4.80/5.0**，详细记录耗时、Token 消耗与多维得分，见 `backend/reports/quality_evaluation_report.md`）。

#### 🦈 支柱三：全局 Gura 助手与有界业务联动
- **全局浮动挂载与路由自适应感知 (#269)**：
  - 提取为独立的 `GlobalAssistant` 全局组件，挂载于应用顶层布局，覆盖 Dashboard、项目主页、章节工作台以及 Studio；
  - 自动感知当前路由与工程/章节上下文，且展开/收起状态与草稿内容通过 `sessionStorage` 在页面流转间无损持久化。
- **有界安全业务工具与交互式卡片 (#268)**：
  - 赋予 Gura 查阅工程概况、大纲摘要、正文草稿、审阅报告、历史还原点及页面按钮使用指南的安全只读能力；
  - 引入有界操作工具（创建新章节 `create_chapter`、页面导航 `navigate_view`、发起审阅 `trigger_chapter_review`），在消息中直接渲染交互式跳转按钮（如 `👉 前往第 2 章`、`👉 前往「编辑审阅」`），点击平滑路由跳转；
  - 严格实施权限边界拦截，杜绝助手擅自篡改正文、定稿或越权发布。
- **会话持久化与上下文隔离 (#267)**：支持工程与章节维度的助手会话持久化，审阅报告查询严格限定在目标草稿版本并区分历史版本统计，避免跨项目与跨版本串扰。

---

### 3. 数据库迁移说明

v0.11.0 包含以下 5 项数据库迁移（基于 Alembic）：
1. `0006_studio_restore_points`：新增 `studio_restore_points` 表，支持手动还原点管理及历史版本映射。
2. `0007_studio_feedback`：新增 `studio_feedback` 与 `studio_feedback_submissions` 表，管理批注与不可变修改提交快照。
3. `0008_restore_point_feedback`：为还原点关联批注与要求快照，支持带批注的全量状态还原与备份。
4. `0009_outline_approval`：为章节添加明确的大纲确认指针 `approved_outline_version_id`。
5. `0010_studio_assistant`：新增 `studio_assistant_conversations` 与 `studio_assistant_messages` 表，持久化助手会话。

---

### 4. 边界声明与已知限制

- **测试替身与真实模型分离**：系统默认以确定性 Provider（`fake`）启动以保证零配置开箱即用及本地快速集成验证；需在配置中指定 `openai_compatible` 及有效 API Key 方可开启真实大模型生成与审阅。
- **外部发布限制**：当前定稿为本地定稿与状态完结，不包含向第三方网络小说平台或商业出版系统的直接推送。
- **助手权限屏障**：Gura 助手仅拥有安全受限的只读状态查询与有界操作引导能力，所有重大创作决策（大纲批准、正文修改、审阅放行、章节定稿）均由创作者自主掌控。

## English Release Notes

### 1. Release Overview

GuraNovel `v0.11.0` is a major milestone release centered around three core pillars:
1. **Frontend Refactor & Studio Stage Orchestration**
2. **Real Agent Capabilities & Quality Benchmarks**
3. **Global Gura Assistant with Bounded Tools**

This release enables writers to experience an end-to-end novel creation workflow—from concept and outline to prose drafting, granular comment revisions, multi-agent editorial review, reader panel critique, and local chapter finalization—all within an ultra-fluid, zero-overflow studio environment backed by authoritative server state and the Gura assistant.

---

### 2. Highlights & Key Features

#### 🌟 Studio Frontend & Persisted Stage Orchestration
- **Integrated Navigation & URL Recovery (#258)**: URL-restored project and chapter states, history preservation, and automatic autosave queue flushing prior to navigation.
- **Authoritative 5-Stage Lifecycle (#261)**:
  - *Outline*: Explicit confirmation opens the author gate and initiates drafting.
  - *Draft*: Author-attributed autosaving, immutable feedback revision snapshots, and idempotent retry safety across network disruptions. Pre-validation failures display non-blocking toasts, decoupling feedback retry from review retry.
  - *Review*: Sequential multi-stage editorial critique (Editor, Chief Editor, Lore), warning consent gates, and targeted revision of selected findings.
  - *Reader*: Multi-agent simulated critique with 6 distinct persona invitations (`studio_*`) and consensus moderation, adhering strictly to a read-only diagnostic contract.
  - *Final*: Local chapter finalization verifying `COMPLETED` workflow state without unverified external platform publishing claims.
- **Editorial Interaction & Motion Stability (#259)**: Strict zero whole-page scroll across mobile, compact desktop, and ultra-wide displays; floating comment controls with dynamic drawer avoidance and drag-to-reorder capabilities.
- **Comment Persistence & Manual Restore Points (#260)**: Fine-grained comment ranges with orphan detection, immutable task snapshots, and atomic backup-before-restore rollbacks.

#### 🤖 Dedicated Agents & Quality Evaluation
- **Standardized Prompts & Versioned Contexts (#262, #263)**: Outline prose content is strictly propagated to writer and revision agents, preventing context insufficiency errors under real model providers.
- **Reader Persona Registry (#265)**: Six dedicated reader profiles (`studio_plot`, `studio_character`, `studio_world`, `studio_emotion`, `studio_language`, `studio_casual`) registered with specialized critique lenses.
- **Real LLM Wiring & Gateway Hardening (#263, #264, #266, #270)**: Robust transport fallback for standard JSON objects on OpenAI-compatible gateways (e.g. DeepSeek-V3), markdown code fence sanitation, and end-to-end benchmark execution (Model: `deepseek-flash`, Pass Rate: 6/6 100%, Score: 4.80/5.0).

#### 🦈 Global Gura Assistant
- **Global Floating Mounting & Route Inference (#269)**: Extracted into a standalone `GlobalAssistant` mounted on root layouts across Dashboard, Project Workspace, Chapter Workspace, and Studio. Route context is automatically inferred, and open/draft states are persisted across route transitions via `sessionStorage`.
- **Bounded Business Actions & Interactive Action Buttons (#268)**: Safe read-only inspection tools (project summary, outline, draft summary, review reports, restore points) plus bounded actions (`create_chapter`, `navigate_view`, `trigger_chapter_review`) with interactive action buttons rendered directly inside messages.
- **Conversation Persistence (#267)**: Project- and chapter-scoped conversation histories managed via Alembic migration `0010`.
