# v0.12.0 桌面个人试写版验收记录

日期：2026-10-14～2026-10-16（Asia/Tokyo）。关联 #313、#297。

本记录限定桌面个人作者流程。两个人工构造的小说样本已完成真实模型调用及本地定稿；这证明流程可完成，不代表模型质量达标或外部出版批准。本文区分开发期、候选版本和最终发布提交；产品版本由独立发布准备 PR #344 统一为 0.12.0，最终合并提交验证与实际发布状态在 #343 和 GitHub Release 中记录。

## 环境与证据边界

- 从独立 clone 构建 Docker；保留原仓库未提交修改，使用隔离 PostgreSQL 和工作区卷。Windows 主机上的后端运行于 Docker Linux 容器；本地定向测试使用 uv，完整门禁使用 GitHub Actions。
- 确定性 Provider 的浏览器操作与 Docker HTTP 冒烟，证明应用行为、版本与持久化；不作为真实模型质量证据。
- 真实调用使用服务端配置的 `deepseek-flash`，`reasoning_effort=none`，单次模型超时 120 秒。通过仅监听容器 loopback 的观察代理转发原始请求；没有替换模型响应。记录耗时、输入摘要和服务商 usage，不记录 Authorization/API key。
- [模型调用台账](v0.12.0-model-calls.json) 按时间、输入摘要和状态去重。HTTP 400 后的受限 JSON 格式回退单列，不能计为额外成功生成；HTTP 200 也不表示返回内容通过业务或质量校验。Reader 的保守 UTF-8 字节计费与服务商 token usage 分别记录。
- 模型抽测跨修复迭代进行：初始长章生成在 109cedf，修订提示词 v3 的实现基线为 805cf82，完成 Reader 的后端为 7f8db09；第二样本也运行在 7f8db09。后续预算结算和缺省题材修复另有定向测试及 Actions，不能将早期模型结果标为最终发布提交的抽测。

## 真实模型样本 A：雾港档案

输入要求：1998 年的雾港，档案员林澈与仍在世的导师沈砚，航海日志缺页；不使用超自然力量、现代手机，不提前揭露最终凶手。输入与版本摘要见调用台账的 `samples.long`。

| 阶段 | 观察结果 |
| --- | --- |
| 三方案 | 原册双签、微缩胶片、第三人借阅单三条事件路径可区分。31.218 秒，860 输入 / 4366 输出 token；选择原册方案。 |
| 正文 | 35.124 秒模型耗时，5666 字符、104 个段落定位符。没有现代手机或超自然解题，导师仍在世。 |
| 首次修订 | 旧 v2 提示词返回 104 段原文，34.01 秒，18731 / 10305 token；质量失败。由此增加 #337 的原样返回拒绝规则。 |
| v3 修订 | 34.936 秒，19041 / 10468 token，5733 字符。加入指定的两句双签对话，修复未冲洗胶卷被当成成片的因果问题。压缩环境描写的要求没有落实；1973/1998 与“封存五十年”的冲突仍存在。结论为部分遵循。 |
| 三类审阅 | Editor 首次无效返回被拒绝，重试成功；产生节奏警告及具体建议，经人工检查后在隔离 QA 明确接受警告。Chief/Lore 通过并有建议。三者漏检上述年份问题。 |
| 可选 Reader | 两位读者、议题提取、讨论、最终投票及编辑交接完成，`simulated=false`。意见指出节奏重复、主角利害不够明确、匿名纸条铺垫不足，具有具体修改方向。 |
| 本地定稿 | 工作流 75eabffb-2c54-4d9c-9ca8-0d7bac83fe2c 已为 COMPLETED；最终版本 efc209d7-c78e-4f2c-90e3-6c0a92569195。Reader 不改写正文；定稿操作只验收机制。 |

Reader 早期分别因 8192 字节输入额度和 4096 字节输出预留失败。提高单次额度后完成，失败记录保留。未填题材被服务端补为 fantasy，造成一位读者要求奇幻要素；#341 修正为 unspecified，不能将这条建议当作有效的设定缺陷。

## 真实模型样本 B：伞铺的收据

输入明确题材为日常生活小说，同一傍晚、同一伞铺，叶禾、周叔、阿敏三人；用收据和现场证据核清两把伞的归属，不添加魔法、犯罪或跨日调查。输入与版本摘要见台账 `samples.short`。

- 三方案生成 11.251 秒，920 / 1385 token；选定收据证据路线。正文请求耗时 18.580 秒，实际 2530 字符，超出输入希望的 900～1200 中文字范围。未做静默截断。
- 修订请求耗时 16.908 秒，模型耗时 16.213 秒，9665 / 5081 token。指定台词“这次是我看错了，你不用替我圆场。”出现一次；周叔推登记簿、放铅笔的短动作已加入，其余正文保持。
- 首次 Editor 报告的证据定位顺序不合约，返回 503/FAILED，原版本保留；重试 `/review` 完成三类审阅。不要用仅用于起草的 `/resume` 恢复审阅；误调用已返回 409，没有修改状态。
- 三类报告给出收据触感、内心解释、伏笔和结尾重复的润色意见，但漏检开篇“阿敏抱两把伞进来”与柜台下已有另一把伞的数量连续性问题。模型报告还是英文，未达到中文意见一致性。
- 未再调用 Reader；该分支为可选，样本 A 已有实际调用。工作流 ec82d097-78a2-46ba-bda0-9bcf013441c8 已为 COMPLETED；最终版本 4286a2a5-a636-4267-a26e-b3df0a7c529d。

## 抽测结论与限制

流程抽测完成，模型质量为部分通过：方案存在差异，具体修订可以落实，评审能给出有依据的建议；同时仍有长度失控、漏改、漏检、无效结构输出及语言不一致。使用者必须检查正文与建议。没有以“多个 Agent 通过”推导作品正确，也没有从两个样本推导普遍成功率。

本期不包含设定讨论、新构思/维护界面、旧 V1 任务续办、完整历史恢复入口、手机适配、封面/简介元数据修复、分卷/改名、助手统一、导出/EPUB、多人协作、公开部署和外部发布。#313 包含这些更广的验收要求，保持开放。
